# Claude Code × Remotion — Motion Graphics com Código

Curso gratuito em PT-BR (formato INEMA.CLUB) sobre gerar **motion graphics de produção com código**, combinando **Claude Code + Remotion** com as bibliotecas certas: **GSAP, D3, Three.js, Lottie e Framer Motion**.

➡️ **[Acessar o curso](https://inematds.github.io/claude-remotion-motion/)**

## Trilhas

1. **Fundamentos & Setup** — instalar a skill, por que ela muda tudo, como promptar (começar simples, iterar).
2. **As Bibliotecas** — GSAP, D3, Three.js, Lottie, Framer Motion: o que cada uma faz melhor, quando usar e como pedir ao Claude.
3. **Projetos Práticos** — 4 peças completas: SaaS walkthrough (GSAP), data-story (D3), comercial 3D (Three.js), onboarding de app (Lottie).
4. **Produção & Entrega** — motion path, render transparente (ProRes 4444 XQ / PNG / alpha) e o ciclo de iteração.

4 trilhas · 16 módulos · cheio de **demonstrações visuais animadas ao vivo** na própria página.

## Base do conteúdo

Material da série "Claude Code × Remotion" (workflow de produção com GSAP, D3, Three.js e Lottie) + os 4 projetos beginner. Render via Remotion (React).
