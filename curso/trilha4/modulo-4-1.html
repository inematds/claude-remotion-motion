Desenhar a trajetória: imagem como input

O fluxo é simples: abra um app de notas, Word, Paint — qualquer coisa. Desenhe uma linha sobre fundo branco. Pode ser à mão livre, com caneta, mouse, ou dedo. Salve como imagem e envie ao Claude com um prompt como "trace este caminho e gera animação que segue exatamente esta trajetória no Remotion".

💡 Dica: qualidade da imagem

Uma linha única, escura, sobre fundo branco. Sem decorações ou texto ao redor da trajetória. Quanto mais limpa a imagem, mais preciso o path extraído.

Por que é mais preciso que palavras

Linguagem natural é ambígua para descrever formas. "Curva suave para a direita que sobe gradualmente" pode gerar dezenas de interpretações diferentes. Uma imagem é univoca — não há margem para interpretação.

✗ Palavras

  • "curva suave" — o quão suave?
  • "para a direita" — qual ângulo exato?
  • "sobe gradualmente" — qual inclinação?
  • Resultado: pode precisar 5+ tentativas

✓ Imagem

  • Forma exata, sem ambiguidade
  • Claude lê as coordenadas do path
  • Primeira tentativa já está certa
  • Resultado: acerto na primeira

Quando usar render transparente

Sempre que o background do Remotion não for o background final do vídeo. Você está criando um elemento que será colocado sobre outro vídeo ou imagem num editor de vídeo (Premiere, DaVinci, Final Cut).

A

Title Cards

Título animado que aparece sobre imagens de abertura. O fundo do Remotion deve ser transparente para o vídeo do NLE aparecer por baixo.

B

Lower Thirds

Nome e cargo do entrevistado animando sobre footage. O overlay precisa de canal alpha para não cobrir a imagem de fundo.

C

Overlays de dados

Gráficos e números animados sobre screencast ou footage de produto. Transparency é o que permite a composição natural.

Erros comuns e como evitá-los

Os três erros mais frequentes que fazem o canal alpha sumir ou a trajetória sair errada. Guarde estes padrões — eles aparecem toda vez que você tenta composição pela primeira vez.

✗ Erros que destroem o alpha

  • •Codec H.264 — não suporta canal alpha. Fundo fica preto.
  • •Picture = JPEG — JPEG não tem canal alpha. Use PNG.
  • •Format errado — se não for a última opção, o alpha achata.

✗ Erros que confundem o path

  • •Imagem poluída — texto, decorações e múltiplas linhas confundem a extração.
  • •Linha muito fina — pode não ser detectada. Use caneta média/grossa.
  • •Fundo colorido — prejudica contraste. Sempre fundo branco.

⚠️ Atenção: os três campos são obrigatórios

Configurar apenas Codec sem mudar Picture ou Format não preserva o alpha. Os três campos precisam ser alterados juntos — são dependentes entre si no pipeline de render do Remotion.
